# 《从零开始写Linux内核》目录与实验映射

本仓库按"章号P节号_实验名"组织实验目录，与书中章节一一对应。
官方最终版源码位于 `../linux_kernel_012/`（Gitee: hinus/linux_kernel_012），官方仓只有成书后的**最终版**代码；
本仓库把最终版代码按书的教学顺序**拆分为渐进式实验**，每个实验独立可构建、可运行（qemu）。

实验目录通用结构：

```
xPy_name/
├── bootsect.S      # 引导扇区（第2章之后的部分实验复用同一份）
├── setup.S         # setup 程序（进入保护模式）
├── kernel/ 等      # 该节引入的内核代码（逐行中文注释）
├── Makefile        # make 生成 linux.img
├── run.sh          # qemu 运行脚本
├── bochsrc.bxrc    # bochs 调试配置（可选）
└── README.md       # 对应书节、运行效果、运行步骤、常见问题
```

## 实验之间的演进关系

```
1P3 hello world (引导扇区显示)
 └─ 2P1 bootsect 加载 setup，setup 采集硬件信息
     └─ 2P2 A20 开启验证 + GDT 定义
         └─ 2P3 实模式中断(IVT)演示，8259A 编程
             └─ 2P4 进入保护模式 + IDT + 时钟中断 ★第一个32位实验
                 └─ 3P1 head.S：分页开启、新 GDT/IDT、栈切换、进入 main
                     └─ 3P2 console + printk 格式化输出
                         └─ 3P3 mem_init + traps + sys_call 骨架
                             └─ 4P1 task0/INIT 进程 + 特权级切换
                                 └─ 4P2 fork 出第二个进程 + 调度切换
                                     └─ 4P3 fork 系统调用 + 写时复制 + 缺页
                                         └─ 5P1~5P4 键盘/终端 (tty)
                                             └─ 6P1~6P4 硬盘/软盘 (块设备+缓冲)
                                                 └─ 7P1~7P6 Minix 文件系统 + exec
                                                     └─ 8P1~8P3 信号/管道/C库 → 完整系统
```

> 每个实验的 README 中会注明：对应书节、与上一实验的差异（新增/删减了什么）、
> 以及与官方仓最终版代码的差异点，便于对照阅读。
